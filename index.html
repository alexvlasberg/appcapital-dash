AppCapital — выручка и начисления

Замена дашборда Metabase: те же цифры — динамика по месяцам, по фискальным периодам и по каждому приложению. Обновляется вручную из выгрузки раз в месяц.

данные на —

Выручка по всем приложениям — календарные месяцы

Сумма факт-выручки всех приложений, по месяцу события (а не по фискальному/платёжному периоду). Отражает фактический перформанс.

Начисления (Proceeds) — фискальные месяцы

Начисления сторов, как их считает Apple/Google (фискальный календарь: первый месяц квартала — 35 дней, поэтому каждый третий месяц выше). Payday: выплата обычно приходит через ~33 дня после конца периода.

Выплаты (Payouts) — по месяцу поступления

Те же начисления, сгруппированные по месяцу фактической выплаты. Когда на один календарный месяц приходится два payday — виден пик.
